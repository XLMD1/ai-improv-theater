## 范围与连接

- 使用用户鸿蒙手机与实际浏览器，记录型号、系统和浏览器版本。桌面视口检查与实机结果分开。
- 先确认 USB 调试或可信 Wi-Fi 条件。默认服务继续监听回环地址；如需要临时局域网入口，先明确访问范围与授权，不直接开放原后端、数据库或所有网卡，不安装调试工具或修改防火墙来绕过授权。
- 使用 Demo／现有已批准本地样本，不生成新故事或图片，不调用付费模型。手机建立独立测试进度，不删除既有用户存档。
- 手机通过可用的官方调试入口连接时使用受支持工具；无法远程控制时由用户在实机执行并反馈，不能用模拟器冒充实体设备。

## 验收步骤

1. [ ] 确认设备、浏览器和连接方式，准备并验证实际可访问入口。
2. [ ] 竖屏故事库、创建表单及样本舞台：无横向拖动、文字截断或重叠；正文完整，按钮可触达，主要操作点击区域符合既定要求。
3. [ ] 人物、线索、调查、历史和分支面板：滚动到底部，关闭入口可达，背景不会抢触控；通过按钮完成调查、移动和一次分支回放。
4. [ ] 软键盘：多行草稿、Enter 换行、发送按钮随滚动可达，收起键盘后布局恢复，系统底部导航／安全区不遮挡。自由文字不提交至付费接口。
5. [ ] 横竖屏切换及浏览器重开：页面能滚动，无控件丢失；当前地点、线索和草稿不变。至少完成 Demo 一条结局路径，再从记录回放。
6. [ ] 遇到问题先复现并定位，再做最小修复和相关验证；记录真实结果、设备、人工人数及限制。没有实际结果的步骤保持待验。
7. [ ] 结束临时连接，恢复仅本机入口；更新阶段进度与开发日志，核对链接和 diff。源码修改时执行相应测试、typecheck 和静态生产构建。
