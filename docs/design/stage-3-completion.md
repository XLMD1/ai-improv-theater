# 阶段三：图片、共享预算与完整故事流程

2026-10-14。继续此前已确认的扩展计划及电影舞台 UI。目标是单用户本地应用的完整自定义故事流程，保持 Demo 无密钥可玩、旧故事原文回放、静态导出和服务端权威。

## 外部接口与价格

已于 2026-10-14 直接读取智谱官方 [定价](https://docs.bigmodel.cn/cn/guide/start/pricing.md)与[图像 API](https://docs.bigmodel.cn/api-reference/模型-api/图像生成.md)：`cogview-4` 在模型枚举中，普通同步调用 0.06 CNY/次，单响应一张图；不使用 Batch 折扣。价格版本 `cogview4-2026-10-14-cny`。参数显式固定 `quality=standard`；五背景 `1344x768`、三人物 `768x1344`。默认保留水印。官方返回 URL 有效期 30 天，必须落地保存。

只开放已有 DeepSeek 文字和 CogView-4 图片；供应商密钥仍只在后端内存。设置页增加智谱密钥字段和共享已支出／已预留／未知结果提示，OpenAI 保持禁用。

## 预算与调用边界

全局 CNY 预算含旧 `llm_calls`、经审核的费用修正、文字及图片。数据库单行预算锁串行化“已支出 + 未结预留 + 本次最大估算”的判断和预留；达到 80 元提醒，达到／超过 100 元拒绝新调用。预留和 attempt_started 在同一独立事务中保存。各次安全重试／修复重新预留。已确认失败且不收费释放；已知实际用量结算；发出后超时、取消、断线或异常响应保留未知费用，阻止新的收费调用直至本地人工核账。

已在飞行的有效预留不视作丢失审计；没有预留／结束记录的旧审计仍阻止调用。结算和费用记录与剧情事务分离。进程启动把遗留预留转换为未知结果记录，不重发请求。旧模型叙事也通过同一执行边界预留和记账，节点语义／保存内容兼容。

注册 `image.generate.v1`（120 秒、至多 3 次，仅明确未受理的连接失败／429 可重试）、`image.download.v1`（20 秒、至多 3 次、安全只读重试，包括外层读取超时；取消不重试）。一套图任务总期限 1200 秒，顺序生成以简化一致性；预算边界独立测试并发。候选图片响应先经严格 schema 校验，下载只接受供应商 HTTPS 主机；2026-10-14 首轮真实 API 三次返回同一个对象存储主机 `maas-watermark-prod-new.cn-wlcb.ufileos.com`，按实际受认证响应加入精确白名单，不泛化放行 ufileos.com；该主机是实测观察，不冒充官方文档列出的主机保证。流量大小上限 12 MiB，图片解码校验类型／尺寸，再原子固定保存、记录 SHA-256。

## 图片任务与恢复

新增独立 `image_tasks`、`story_assets`，绑定会话与已批准故事版本。新增客户端创建的自定义会话要求图片就绪；旧会话默认保持历史准入，不追溯阻断。确认仍生成旧协议根节点，但新会话未准备完成前服务端拒绝行动。

每套任务八个固定实体槽位，提示只取故事年代／公开环境／人物外貌，绝不送真相、秘密、未发现证据；全部人物共享同一风格和外貌卡。封面使用起始场景，结局复用最后地点图；不额外生成。已完成素材不可覆盖。

状态：pending → generating → download_pending → ready；明确失败为 failed；结果未知为 uncertain。生成成功的临时 URL 立即存检查点，已知成功但在 URL 主机校验／检查点处中断时，经当前严格 schema 重验原保存输出后补回 URL，不重新生成。下载失败后恢复只下载，不再次生成；ready 跳过。任务创建和恢复均用幂等键、会话锁；一次只跑一个套图任务。进程重启中断任务，显式恢复只补缺，uncertain 槽位需要核账后才允许明确新尝试。费用未知时不显示“免费重试”。

接口：认证的 `POST /image-tasks`、`GET /image-tasks/{id}`、`POST /image-tasks/{id}/resume`、`GET /session/assets`、`GET /assets/{id}`。跨会话均拒绝；进度只暴露数量、状态、错误码及公开实体名，不暴露提示、临时 URL、路径、秘密或密钥。图片读取鉴权后返回固定本地文件；前端用带授权的 blob 请求显示，不把令牌放在 URL。

## 前端与本地存档

首页故事库、固定 `/create` 与 `/play?id=...`，仍静态导出。持久化版本化故事库：每局 token、session ID、文字模型、创建请求／幂等键／任务、图片任务／恢复键、当前节点、自由输入、行动 pending；API Key 永不进入库。旧 sessionStorage 迁入库并保留原凭据／节点／待完成行动，不自动新建局。创建请求在网络发出前保存；返回后固定 task ID，重连复用原 key；只有明确新任务才换 key。

创建表单（背景≤500 字、三年代、DeepSeek）→ 服务端真实进度 → 无剧透简介确认 → 八图准备／补缺 → 舞台。根节点／当前节点和任务能跨关闭浏览器恢复；后端重启须重填供应商密钥，但已保存正文／素材与无外部调用的 R1 按钮仍可回放。

调查世界通过认证 `/session/world?node_id=...` 读取，动态角色／地点 ID；公开人物、对象、证据、披露、承诺与终局从该投影读取。按钮仍直接提交已保存 option ID，不在浏览器解释规则。人物交流、调查、出示、移动按服务端选项分组；人物卡提供当前可交流选项，已发现证据卡提供出示目标，当前地点调查对象面板提供对象及调查选项。公开节点仅增加已保存可用选项的角色／对象／证据／地点 ID，禁止公开条件、效果及终局目标。面板按钮仍提交原 option ID，关闭面板后在舞台显示结果；自由输入走原 R1 解释。历史只读祖先，全部分支保留。R1 空对白直接读 narration。

视觉延续电影舞台：故事库封面卡、创建和准备页用冷青底／暖金操作；手机规范沿用 [UI 文档第 10 节](stage-3-ui-design.md#10-响应式布局)。长选项可滚动，终局／回放不另起供应商请求。

## 验证与完成口径

先跑冻结兼容测试，增量迁移只在独立 `stage3_20261014_test`。覆盖预算真实并发、失败结算、未知结果、重启审计、跨会话素材、幂等／补缺、损坏／错误尺寸、重试耗尽、图片未就绪准入、旧准入、浏览器库迁移与 pending 恢复。真实 HTTP 评测调用前用仅专用 `_test` 库返回的非敏感数据库指纹核对服务与运行器的主机／端口／库名，指纹不包含账户或密码，失配时不创建会话或收费任务。运行后端相关／完整 pytest、前端测试、typecheck、build、迁移差异检查。

真实三年代必须各创建／配八图／完整走三结局并核对外貌与年代；记录耗时、次数、usage、费用和人工评审数。模拟成功不计真实成功。没有密钥或没有真实验收时保持整阶段未完成，并明确列出剩余项。保存截图和开发日志，提交仅含本阶段代码／文档，不带用户数据和旧草稿。

真实清单允许显式 `--resume-report`：仅从本运行器 runtime/evals 内、同冻结清单的原报告恢复已批准根节点／凭据及已有图片任务，不重新创建已批准故事。每轮报告与源报告分别保存，保留首轮失败和额外费用；结果未知仍需人工核账，不因恢复评测绕过边界。

恢复评测已成功的路径只核对固定根／终局／祖先链并回放原节点，不再调用行动理解；源失败报告保留，补测只执行未完成项。


2026-10-14 视觉核查修订：cinematic-public-1把全部人物卡同时放入每个提示，实图出现双人肖像和背景人物，未通过图片质量门槛。cinematic-public-2仅向人物槽提供该目标的一张外貌卡；背景不提供任何人物卡，明确只取环境陈设，禁止人像。年代用明确中文名称，保持统一风格、大小和模型。完成的v1图及报告冻结保留；v2仅用于新建套图任务，不覆盖已有素材。先以已确认但未配图的界面样本验证v2，再按用户选择继续新三年代或保持未验收。


## 已确认补充：本地样本无密钥试玩（2026-10-14）

用户确认将新版古代、近现代、未来三局验收样本保留在本机故事库，按钮调查、交流、出示证据、移动、三个结局与回放无需外部 API。自由文字仍走既有 AI 理解流程，页面明确提示需要 API 密钥。原样本、旧存档与已完成图片不覆盖。

本地服务从 Git 忽略的 runtime/local-samples.json 读取显式发布的故事版本白名单，仅提供已批准、R1 呈现且八图完整校验通过的版本；按用户保留为本地试玩的要求，技术校验齐备的验收样本可保留试玩，画面瑕疵明确记录；保留试玩不代表阶段三图片质量通过。接口只公开标题、年代和无剧透简介，不暴露完整设定、原会话或凭据。每次开始创建独立会话与根节点，复用同一固定版本及本地素材；原分支不复制。客户端先持久化自己的会话凭据再发请求，重试复用该凭据。

复用素材按已认证会话的固定 story_version_id 鉴权，其他版本仍隔离；样本禁止创建或恢复生图任务。数据库与 runtime/generated-images 必须一起保留，依赖本地服务，不等于纯浏览器离线或阶段四便携包。尚未登记时不显示空样本入口。验证无密钥新开、三结局与回放，外部调用和账本增量为零；跨版本访问、未批准/损坏素材、幂等、关闭后恢复及前后端检查。

2026-10-14 保留结果口径：新版固定清单古代/近现代各通过五项，未来候选一次修复后语义未通过，10/15，原报告保留。第三个本地试玩使用此前在界面真实创建并批准、按 v2 准备八图的《轨道城货单缺口》；不得用它替换失败清单或宣布15/15。新版单人肖像问题已消除，但古代码头仍画有路人、画像年龄/饰物和附加文字有偏差，保留图像质量未完全通过状态。样本卡明确为测试样本、配图待验收。


## 已确认补充：删除本机游玩记录（2026-10-15）

故事库每局卡片提供独立的“删除记录”按钮，与继续故事链接分开。原生 dialog 展示故事名和不可恢复的范围，默认焦点在取消，支持 Escape；确认后仅更新浏览器故事库并清理当前标签页匹配的旧 sessionStorage 恢复信息，不调用服务端删除或模型接口。保留凭据的 SHA-256 单向摘要作为删除标记（不保留原凭据），阻止其他旧标签页重新迁入已删记录。删除当前记录时清除 currentId，保留其他记录；写入失败时显示错误，不宣称删除成功。服务端故事、图片、费用及本地样本目录保留，样本和 Demo 可重新开局。若记录含待恢复任务，弹窗说明删除不取消已发出的任务。

验证删除指定记录及其恢复信息、当前项指针、其他存档隔离、旧迁移不复活、重复删除和存储失败；通过实际浏览器验证取消、确认、刷新、键盘与手机宽度。仅用新建测试记录验收，不删除已有用户存档。阶段三原有未通过项继续保留。
