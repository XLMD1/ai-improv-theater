# 2026-10-15 本机游玩记录删除

## 用户确认范围

故事库“继续你的旅程”卡片提供删除记录入口。用户确认后移除本机该局的进度、草稿、凭据、任务恢复信息；服务端故事、图片、费用以及样本和 Demo 开局入口保留。需求先更新于 [产品需求](../01-requirements.md) 和 [阶段三设计](../design/stage-3-completion.md)。

## 实施

- 继续故事链接与删除按钮独立，原生确认弹窗显示故事名及影响范围；默认焦点在取消，Escape/取消返回原按钮，成功后聚焦故事库标题并宣布结果。失败保留错误提示。
- 删除操作重新读取当前故事库，只移除选中项；清理 currentId 和当前标签页匹配的旧 sessionStorage 恢复字段。保留原凭据的 SHA-256 单向摘要，阻止其他旧标签页迁回已删记录；原凭据和草稿不保留在删除标记中。
- 迁移和删除使用浏览器 Web Crypto，初始化在第一次 await 前锁定 busy，防止 Strict Mode/并发初始化重复开局。跨标签页故事库变化会更新卡片列表。
- 一位独立 AI 审查者发现旧标签页重新导入和异步初始化防重入两项问题；均补充失败测试后修复，复核确认。没有人工审查计数。
