# 电影舞台前端首轮实施

日期：2026-10-13。用户确认 [UI 设计文档](../design/stage-3-ui-design.md)后，按[实施计划](../superpowers/plans/2026-10-13-cinematic-ui.md)完成现有故事游玩页改造。手机规范位于 UI 文档第 10 节，第 5、7、8 节补充裁切、输入和全宽面板。

## 实际交付

- 电影舞台、真实美术背景、桌面两栏与手机纵向布局，保留 Next.js 静态导出。
- 服务端批准正文逐句阅读／完整展开、全部真实选项、500 字自由输入、多行与 Ctrl/Cmd+Enter。
- 当前故事、公开人物、当前节点已知记录、祖先历史、不可变分支回放及结局入口。
- 阅读速度／减少动画偏好；沿用现有本地模型设置，OpenAI 继续禁用，密钥存储方式不变。
- 草稿保留、任务幂等恢复、未知结果阻止第二个提交；明确拒绝或终止任务解除锁定且不改变父节点。
- 六张固定 WebP 美术素材：候船厅、档案室、码头、钟楼、灯塔、清晨。总计约 2.14 MiB；由设计生图生成，与运行时 CogView-4 接入分开。素材冻结后回放直接复用。

删除改造产生的未使用 SceneArt 模块；没有改写既有后端和四份无关草稿。未提交运行数据库、日志或密钥。

## 验证边界

这次通过的是现有 Demo／旧 DeepSeek 前端展示与 Demo 可玩链路，没有重新调用真实 DeepSeek、验证 CogView-4 或完成自定义故事创建流程。Demo 验证没有调用文字供应商，未新增文字调用 usage；不据此报告生成模型时延或费用。设计美术生图费用未取得计费回执，不编造金额。

内置浏览器不支持本轮使用的原生缩放快捷键，200% 原生缩放未验证；720px 等效重排已检查。实体手机软键盘、安全区与屏幕阅读器尚待实机确认。无对白与长文本字符保全是自动测试结果，不描述为真实模型剧情验收。

自定义故事创建／确认／配图准备、CogView-4 定价与注册工具、文字图片共享预算、跨浏览器重启的多故事库仍属于阶段 3 后续交付项，主计划保持未完成。没有把静态设计美术当作运行时生成图片功能。
