## 可复现入口

安装后端测试依赖。以下 `python` 指仓库虚拟环境 Python；从根目录运行。

```powershell
# 无模型调用的规则检查
python evals/run_stage1.py --suite rules
# 需要已迁移的独立 PostgreSQL *_test 库；MIGRATION_DATABASE_URL 只放进程环境
python evals/run_stage5.py --suite runtime_simulated
# 新的完整 DeepSeek 实测，终端隐蔽输入密钥；费用记入测试库账本
python evals/run_stage5.py --suite real_model --prompt-key
# 对已有真实 report.json、冻结文件和同库记录只读提取
python evals/run_stage5.py --suite recorded --source-report <本地原始报告> --human-review <同轮人工验收>
# 对采集出的本地 bundle 重新计算指标，无需数据库、密钥或网络
python evals/run_stage5.py --suite replay --bundle <本地bundle.json>
```

人工验收参数可省略，此时事实一致性明确显示 not_reviewed。没有密钥的真实运行仍保留固定分母并退出非零，不能回退 Demo 后算通过。每次输出独立 `runtime/evals/stage5_<id>/`，不覆盖原记录。重算接受源清单原始 hash 或严格 LF 等价内容，处理 Windows CRLF 检出；任何实质清单差异拒绝。成功路径核对固定结局索引、输入类型及冻结行动序列，版本元数据交叉核对；旧失败报告缺 run ID 时显示覆盖不全、完整费用为空。缺应计费账单或 attempt、重试顺序不完整及证据包改动均拒绝。

历史原件包含故事、候选与内部事实，因此不打包到仓库。干净源码可以运行规则、模拟和自己的真实评测；无法仅凭公开聚合 JSON 独立重验私人原始模型输出，不能声称原始数据已公开。

## 保留的限制

新故事共享调查结构，AI 不能创造新动作或改写固定真相；R1 多数回合没有动态对白。仅三个故事与一位历史评审，不能推导普遍 AI 质量。手机实机未测、自动生图视觉失败继续保留；本轮不重新验收付费图片、手机、Docker 或已取消的模型和多 Agent。
