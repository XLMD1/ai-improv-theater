# 阶段三固定本地验收

固定清单：[stage3.json](../../evals/cases/stage3.json)。三年代各一次真实创建、一次八图准备、三条完整结局路径，总计 15 项。第一条路径使用自由文本，其余使用保存的选项 ID；无效或重复行动不得推进状态，独立 pytest 故障套件验证此项，不计入真实 15 项。所有结局路径从已确认版本的规则证明冻结取得，内部读取证明用于选择玩家输入，不作为玩家生成上下文。

运行器通过已启动的本地 HTTP 服务使用内存密钥，只允许本机地址和独立 `_test` 数据库。API Key 不进入命令行或报告。每项须完成对应校验才记 succeeded，失败和未运行依赖保留在分母；真实结果与 pytest 模拟故障分开报告。输出位于忽略的 runtime/evals 下，凭据单独保存以供本机恢复，公开报告不含令牌。

图片检查：八个槽位的尺寸、PNG 解码、落地校验值和鉴权读取一致，重复读取／幂等 start 不新增生成调用。视觉匹配需另看每年代所有图片并记录实际人工人数；代码审查人数和模型图像评审人数分别记录，不以自动文件校验替代外貌／年代核查。浏览器窄屏、存档恢复和交互截图另记 design-qa.md。

记录每项耗时、真实调用数、input/output tokens、image_count、价格版本、估算及未确认费用。不把估算称为供应商实际扣款，不把存档 R1 规则反馈称为模型叙事。
