# AI 即兴剧场：分阶段开发与验收

版本：v0.3（DeepSeek 优先，OpenAI 待开发验证）

## 工作方式

每阶段先对照需求和技术设计确认边界，再实现、运行该阶段测试、提交。Commit 标题统一为 `English: 中文`，例如 `docs: 建立需求与技术设计`、`feat: 实现分支存档`、`test: 覆盖中断恢复`。未经过验证的代码不标记完成。

三文档建立前的模型、记忆和 Docker 草稿仍留在原工作目录，未进入阶段 1 提交；后续仅在重新测试通过后选择性重写或采用。它们不能视为通过测试、可运行或可写进简历的成品。

## 最高优先级的十项测试

1. 缺字段或多字段的单次模型输出进入安全过渡幕，非法候选稿不提交。
2. 非法场景转移被拒。
3. 越权状态键不改变快照。
4. 越权角色或机器可判定的状态冲突进入安全过渡幕，状态变更为空；自然语言矛盾另作人工评测。
5. 无密钥、失效密钥和网络错误使任务失败，且不创建幽灵节点。
6. 同父节点两分支的状态与记忆隔离。
7. 修改模型/prompt 后旧节点仍原样回放。
8. 祖先上下文不召回另一分支的事件。
9. 并发提交同一幂等键只创建一个 run 与节点。
10. SSE 断线补发不重不漏；重启未提交任务无幽灵节点。
