## 1. 工作方式与状态口径

交付顺序为 **游戏体验 → 求职作品交付 → 多 Agent 默认模式**，取消按周划分的开发期限。每阶段执行“更新规范 → 实现 → 测试 → 本地验收 → 开发日志 → 相关提交”，Commit 标题采用 `English: 中文`。

以下阶段 0–6 是本轮唯一有效编号。旧基线的阶段、勾选及历史测试数字在本文历史部分保留，不继承为新阶段完成状态。已有状态更新、不可变节点、分支存档、幂等、SSE、最近三个祖先回合上下文和一条 DeepSeek 真实路径可以复用；阶段 2 自定义故事及调查后端已按方案 A/R1/v2 验收；图片、完整新前端、便携包、OpenAI 文字和多 Agent 仍待后续阶段验收。

未跟踪的 `backend/app/generators.py`、`backend/app/llm.py`、`backend/app/memory.py` 和 `docker-compose.yml` 仍为独立草稿，未经明确纳入并验证不改写、不提交。生成故事、图片、数据库、密钥和本地日志使用 Git 忽略的运行目录。

## 3. 验证与记录要求

| 验证类 | 关键检查 |
|---|---|
| 规则与兼容 | 无效行动、非法状态、证据依赖、重复调查、结局可达、旧存档、换模型/prompt 后原样回放 |
| 隔离与恢复 | 跨故事授权、兄弟分支排除、同键真实并发、SSE 不重不漏、进程重启、图片补缺 |

后端修改从 `backend/` 运行相关 pytest；迁移仅在独立测试库执行 `alembic upgrade head` 与 `alembic check`。前端修改从 `frontend/` 运行相关测试与 `npm run typecheck`，行为或打包变化运行 `npm run build`。开发启动使用 `pwsh -NoProfile -File .\scripts\start-local.ps1`，数据库与 PowerShell 5.1 配置见 [README](../README.md)。

### 旧基线最高优先级的十项测试

1. 缺字段或多字段的单次模型输出进入安全过渡幕，非法候选稿不提交。
2. 非法场景转移被拒。
3. 越权状态键不改变快照。
4. 越权角色或机器可判定的状态冲突进入安全过渡幕，状态变更为空；自然语言矛盾另作人工评测。
5. 无密钥、失效密钥和网络错误使任务失败，且不创建幽灵节点。
6. 同父节点两分支的状态与记忆隔离。
7. 修改模型/prompt 后旧节点仍原样回放。
8. 祖先上下文不召回另一分支的事件。
9. 并发提交同一幂等键只创建一个 run 与节点。
10. SSE 断线补发不重不漏；重启未提交任务无幽灵节点。
